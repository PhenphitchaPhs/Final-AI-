# ระบบเขียนโพสต์โซเชียลด้วย AI (AI Social Media Post Generator)

เว็บแอปที่ช่วยเขียนโพสต์ลงโซเชียลมีเดียอัตโนมัติด้วย AI
ผู้ใช้เพียงกรอกหัวข้อที่ต้องการ เลือกโทนของข้อความ (เช่น สนุกหรือจริงจัง)
และเลือกวัตถุประสงค์ จากนั้นระบบจะเขียนโพสต์ให้เหมาะกับแต่ละแพลตฟอร์ม
(เช่น Facebook และ Twitter/X)

## เทคโนโลยีที่ใช้
- Frontend: Next.js, TypeScript
- Automation & AI: n8n เชื่อมต่อกับโมเดล AI
- Deploy: Vercel
